The campaign vault: Russian-language Obsidian-style Markdown that is the published site. 59 tracked Markdown files plus 45 images. This file covers the vault-wide contract; each subfolder documents its own shape.

## THE PUBLISHING CONTRACT

- `draft: "true"` (quoted string) is the only frontmatter key used in the vault. The `remove-draft` plugin strips those pages from the build. Publishing = deleting that key.
- `title`, `tags`, `aliases`, `description`, `cssclasses` and `date` are not used anywhere except `title` on `index.md`. The `note-properties` plugin renders `description`/`tags`/`aliases` only, and the vault supplies none.
- Wikilinks are the backbone: `[[Note]]`, `[[Note|Alias]]`, `[[Note#Section]]`, `[[Note#Section|Alias]]`. `crawl-links` resolves them with `markdownLinkResolution: shortest` and `disableBrokenWikilinks: true`.
- Image embeds are `![[file.png]]` or `![[file.png|294]]`, resolved flat against `content/images` (no subfolders).
- `%% ... %%` is the hidden/GM-only channel; it is stripped at render (`obsidian-flavored-markdown`, `comments: true`) but stays in the source.
- `ignorePatterns: [private, templates, .obsidian]` keeps those folders out of the build.

## CONVENTIONS

- Filenames are the entity display name, never slugified: Cyrillic, spaces, `«»`, `№`, parentheses, apostrophes (`Де'Рела`), and even combining diacritics (`Э́стер.md`, `Интериóр Небесной Бездны (Свод).md`).
- Mechanics stay half-English inside Russian text: `Mark a Stress`, `Spend a Fear`, `range: Melee` and `range: Вплотную` appear side by side.
- Distances are Russian (`Вплотную / Близко / Средне / Далеко / Очень Далеко`), damage types are `физ`/`маг`.
- A ` TODO` filename suffix marks an unwritten note; an `admin ` prefix marks GM-only encounter material.
- There is no `index.md` in the subfolders - folder listings are generated by the `folder-page` plugin.

## ANTI-PATTERNS

- `disableBrokenWikilinks: true` means a link to a missing file silently stops being a link. There is no build error - check the target file exists before renaming an entity.
- Never rename an entity without fixing every inbound wikilink; wikilinks point at basenames, so a rename breaks every reference at once.
- Never put campaign content into `docs/` - that folder is the vendored Quartz documentation and is built as a separate site.
- Do not run `npm run format` over `content/`. Prettier covers `content/**/*.md` (only `public`, `node_modules`, `.quartz-cache` are ignored) and would rewrite the hand-formatted campaign prose.
- `content/images/` mixes four naming styles (md5 hashes, semantic lowercase names, `Pasted image <timestamp>.png` dumps, TitleCase). Match an existing style of the file you edit instead of renaming assets; a renamed image breaks every embed silently.

## HOTSPOTS

`content/index.md` is the link hub of the vault. `content/Локации/Полярис/Подземье/Дворец Последнего Императора/Подземье.md` is the hub of the largest dungeon. `content/Приключение/Post Mortem.md` holds the standing DM rules.

## COMMANDS

- `npx quartz build` - builds the vault (default `-d content`) into `public/`.
- `npx quartz build --serve` - local preview of the campaign. `npm run docs` previews `docs/` instead - not this vault.
